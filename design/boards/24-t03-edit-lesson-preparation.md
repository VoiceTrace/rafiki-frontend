# Board 24 - T03 edit lesson preparation

![T03 edit lesson preparation](24-t03-edit-lesson-preparation.png)

## Purpose

Detailed standalone desktop reference for **B3 Edit generated prep** within the existing T03 Before-class page.

## Required UI

- Narrow unsaved-changes strip under the phase tabs.
- Inline objective edit control.
- Expanded editable warm-up question with enable toggle, Save, Cancel, and remove action.
- Lesson-flow ordering handles and edit/remove controls.
- Editable checks for understanding.
- Explicit page-level **Save changes** and **Cancel** actions.

## Required related states

Keep/discard confirmation, validation errors, save success, and save failure/retry use the same in-context pattern. Do not redirect the teacher to a separate editor.
