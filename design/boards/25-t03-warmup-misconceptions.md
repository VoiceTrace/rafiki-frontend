# Board 25 - T03 warm-up misconceptions

![T03 warm-up misconceptions](25-t03-warmup-misconceptions.png)

## Purpose

Detailed standalone desktop reference for **B6 Review class misconceptions**, integrated into the existing T03 Before-class page.

## Required UI

- Compact lavender **Warm-up misconceptions** card directly below the Socratic warm-up content.
- Ranked misconception, aggregated answer count, and anonymized evidence excerpts.
- Sage teaching-suggestion row that helps the teacher act before class.
- Visible directions for populated, no responses, processing, and analysis-failed/retry states.

## Privacy boundary

Evidence must remain anonymized and aggregation must follow the product's consent and minor-data policy. The design does not authorize exposing identifiable student answers.
