# Board 23 - T03 generated lesson-draft review

![T03 generated lesson-draft review](23-t03-generated-draft-review.png)

## Purpose

Detailed standalone desktop reference for **B2 Generate lesson prep with AI** after a draft is available. This is the existing T03 Before-class page, not a new generation screen.

## Required UI

- A slim Rafiqi draft-review strip below the phase tabs.
- Explicit **Keep draft** and **Regenerate** decisions.
- Small **AI draft** labels on generated objectives, warm-up questions, lesson-flow segments, and checks.
- All normal T03 preparation cards remain visible and reviewable.

## Boundaries

This screen is frontend UI direction only. Generation, source grounding, saving, and publication require later services. Loading and failure are defined in Board 21; mobile Arabic direction is Board 22.
